Алгоритм решения
1.НАЧАЛО.    
2.Ввести символ c.    
3.Сравнить c со значениями вариантов выбора: строчная и заглавная буква считаются одним вариантом (например, 'а' и 'А').  
4.Если c = 'а' или 'А', вывести «Буква c — 1-я буква алфавита» и перейти к пункту 8.  
5.Если c = 'б' или 'Б', вывести «Буква c — 2-я буква алфавита» и перейти к пункту 8.  
6.Аналогично для остальных букв: для буквы с номером N (от 3 до 33) вывести «Буква c — N-я буква алфавита» и перейти к пункту 8.  
7.Если c не совпало ни с одним вариантом (default), вывести «Символ c не является буквой русского алфавита».
8. КОНЕЦ.
